# Assignment requirements and submission checklist

Source: ProjectAssignment.pdf, reviewed directly on 2026-10-26 (all three pages). The requirements below are confirmed from the source. Current delivery is the frontend prototype only; SQL/PHP requirements remain unimplemented.

## Required implementation
- At least seven tables (the supplied design has 30).
- Implement using phpMyAdmin, with sufficient records for testing.
- At least seven complex business questions answered by SQL, each involving at least two tables.
- Suitable data types/sizes, primary keys, foreign keys, and CHECK constraints in at least three tables.
- Three triggers.
- Three procedures or functions.
- Three cursors.
- PHP web interface connected to the database, displaying query results in suitable web formats.

## Submission
- Final presentation: 20 minutes.
- Final paper: introduction, system overview, table diagram, implementation methods, main query examples, real execution screenshots of major trigger/procedure/cursor examples, discussion/conclusion, lessons learned, and references.
- Paper length: 12-13 pages excluding cover and table of contents; Times New Roman 12 pt; line spacing 1.15.
- ZIP containing paper PDF, SQL/PHP source, and readme.txt with authors, project overview, file structure, and setup instructions.
- All members contribute; peer assessment is included in grading.
